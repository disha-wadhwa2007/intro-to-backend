# Backend Tutorial – Node.js, Express.js & MongoDB

## Project Description
This project is a RESTful Backend API developed using Node.js, Express.js, MongoDB Atlas, and Mongoose.

It demonstrates CRUD (Create, Read, Update, Delete) operations using Express controllers and routes.

All APIs are tested using Postman.

## Technologies Used
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Postman
- Nodemon
- Git & GitHub

## Features
- MongoDB Atlas database connection
- User model using Mongoose
- RESTful APIs using Express.js
- CRUD operations
